PRODUCT LOGOS — one file per product, named after the product slug.
To change a logo, replace that file (keep the same name), e.g.:
  fake-lag-pc.webp  ->  logo of FAKE LAG PC
Files: PNG/WebP, square-ish, ideally 512x512. Transparent background looks best.
abnormal-logo.webp = ABN logo, br-logo.webp = BR logo (spare copies).
